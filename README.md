# 🇪🇸 Selección Española de Fútbol

Aplicación móvil desarrollada con **React Native** y **Expo** que presenta información básica sobre la Selección Española de Fútbol. La aplicación cuenta con una navegación sencilla entre tres pantallas y una interfaz amigable.

## 📱 Funcionalidades

- Splash Screen de bienvenida.
- Pantalla principal con información sobre España como campeón mundial.
- Botón para navegar a la pantalla de jugadores destacados.
- Pantalla con información de los jugadores más representativos de la selección.
- Botón para regresar a la pantalla principal.
- Navegación implementada con Expo Router.

## Tecnologías utilizadas

- React Native
- Expo
- Expo Router
- TypeScript
- JavaScript

## Pantallas

### Splash Screen
Pantalla de bienvenida que se muestra al iniciar la aplicación durante unos segundos antes de ingresar al menú principal.

### Home
Muestra el título **"España Campeón Mundial"**, una imagen representativa y un botón que permite acceder a la pantalla de jugadores destacados.

### Jugadores Destacados
Presenta información e imágenes de algunos jugadores importantes de la Selección Española y cuenta con un botón para regresar a la pantalla principal.
